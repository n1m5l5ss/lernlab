# Example decks

Small decks written for this project and released under **CC0** (public domain). Import them from **Decks → Import → File**.

| File | Subject | Shows |
|---|---|---|
| `aws-cloud-basics.csv` | Cloud (AWS) | categories for the sorting sprint, multi-select questions with explanations, an ordering question |
| `biology-cells.tsv` | Biology | Quizlet-style tab-separated terms, a cloze card |
| `german-a1-starter.csv` | German | set the deck language to German for articles, speaking and sentence building |
