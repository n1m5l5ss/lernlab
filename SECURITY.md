# Security

LernLab opens deck files that people share with each other, so a malicious deck is a real risk. Please report security problems privately, not in public issues. Use GitHub's "Report a vulnerability" button on the Security tab of this repo.

Include:
- what you found;
- how to reproduce it (an example deck file helps);
- what an attacker could do.

You'll get a reply within 7 days.
